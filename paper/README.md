# Associated paper

This directory intentionally contains no manuscript or unpublished research material.

Once the work is public and sharing is approved, add:

- the paper title;
- authors in publication order;
- journal or conference;
- year, volume, issue, and page/article number;
- DOI and an authorised public link;
- a short statement connecting the repository version to the paper;
- a BibTeX citation.

Suggested template:

```text
Title: [Paper title]
Authors: [Authors]
Venue: [Journal or conference]
Year: [Year]
DOI: [DOI]
Repository release: [Git tag or archived DOI]
```

```bibtex
@article{your_key,
  title   = {[Paper title]},
  author  = {[Authors]},
  journal = {[Journal]},
  year    = {[Year]},
  doi     = {[DOI]}
}
```

Do not upload publisher PDFs unless the publication agreement permits it. Link to an authorised version instead.
